Deutsch

V3.1.1 (aktuell)

  • Fix: Bei einer Windows-Skalierung über 100 % öffnete das Fenster größer als der Bildschirm. Die Arbeitsfläche wurde in physischen Bildpunkten gemessen, aber als geräteunabhängige Einheiten gesetzt — bei 125 % ergab das 1750×1102 auf einer Arbeitsfläche von 1920×1020. Jetzt wird korrekt umgerechnet.

V3.1.0

Wartungs-Update — besonders auf kleineren Notebook-Bildschirmen empfohlen.

  • Fix: Das Fenster passte nicht auf 1366×768. Es öffnete 760 Pixel hoch, obwohl über der Taskleiste nur 720 bleiben — die Unterkante lag dahinter. Jetzt wird die Mindestgröße aus der nutzbaren Arbeitsfläche abgeleitet, bevor eine Größe gesetzt wird.
  • Fix: Network Watch maß weiter, nachdem man die Seite verlassen hatte. Nur die Anzeige stoppte; die Messschleifen liefen bis zum Beenden der App und hielten den Rechner dauerhaft beschäftigt. Beim Seitenwechsel wird die Messung jetzt beendet und das im Live Log vermerkt.
  • Fix: SFC, DISM, Winsock und Store-Reset ließen sich nur mit der Maus auslösen — kein Fokus, keine Tastatur, nichts für Bildschirmleser. Es sind jetzt richtige Schaltflächen, gleiches Aussehen plus Kurzhinweise.
  • Update: Der Hauptknopf hieß „ALLE REPARATUREN AUSFÜHREN“, leerte aber nur den DNS-Cache. Er heißt jetzt „DNS-REPARATUR AUSFÜHREN“.

Download V3.1.0

V3.0.9

Nachtrag zum Sicherheits-Update v3.0.8 — für alle empfohlen.

  • Fix: Beim Bereinigen von Temp löschte der Cleaner die Entpackordner laufender Programme (%TEMP%\.net\). Jitvora traf das selbst: Nach dem Bereinigen stürzte die App beim Schließen ab und legte eine Datei namens Jitvora_Crash_Log.txt auf den Desktop. Diese Ordner bleiben jetzt unangetastet — die eigenen und die fremder laufender Programme.
  • Fix: Das Live Log meldete übersprungene Verknüpfungen nie. v3.0.8 hatte diese Meldung zugesagt, sie ging aber auf dem Weg aus dem Hintergrund-Thread verloren. Sie kommt jetzt an, mit richtiger Anzahl.
  • Fix: Absturzberichte landen nicht mehr auf dem Desktop, sondern unter %LOCALAPPDATA%\Jitvora\Logs\ — und verschwinden beim Deinstallieren.
  • Update: Die Einstellungen sagten „Vollversion — alle Funktionen aktiv", obwohl das Pro Center nur eine Vorschau ist. Jetzt steht dort, was stimmt.
  • Update: Das Live Log nennt auch die Ordner, die wegen laufender Programme übersprungen wurden

English

V3.1.1 (current)

  • Fixed: with Windows scaling above 100% the window opened larger than the screen. The work area was measured in physical pixels but applied as device-independent units — at 125% that produced 1750×1102 on a 1920×1020 work area. It is converted correctly now.

Download V3.1.1

V3.1.0

Maintenance release — recommended especially on smaller laptop screens.

  • Fixed: the window did not fit a 1366×768 screen. It opened 760 pixels tall while only 720 remain above the taskbar, so the lower edge sat behind it. The minimum size is now derived from the usable work area before a size is assigned.
  • Fixed: Network Watch kept measuring after you left the page. Only the display stopped; the measurement loops carried on until the app closed and kept the machine busy. Navigating away now ends the measurement and notes it in the Live Log.
  • Fixed: SFC, DISM, Winsock and store reset could only be started with a mouse — no focus, no keyboard, nothing for screen readers. They are proper buttons now, same look plus tooltips.
  • Changed: the main button said “RUN ALL REPAIRS” but only flushed the DNS cache. It now says “RUN DNS REPAIR”.

Download V3.1.0

V3.0.9

Follow-up to the v3.0.8 safety release — recommended for everyone.

  • Fixed: cleaning temp deleted the unpack folders of running programs (%TEMP%\.net\). Jitvora did this to itself: after a cleanup it crashed on exit and dropped a file named Jitvora_Crash_Log.txt on the desktop. Those folders are now left alone — its own and those of other running applications.
  • Fixed: the Live Log never reported skipped links. v3.0.8 promised that notice, but it was lost on the way out of a worker thread. It now arrives, with the correct count.
  • Fixed: crash reports no longer land on the desktop. They go to %LOCALAPPDATA%\Jitvora\Logs\ and are removed when you uninstall.
  • Changed: Settings said “Full version — all features active” although the Pro Center is preview-only. It now says what is true.
  • Changed: the Live Log also names folders skipped because a running program is using them

Download V3.0.9

V3.0.8

Safety release — recommended for everyone who uses the Cleaner.

  • Critical fix: the Cleaner followed directory junctions and symbolic links and could therefore delete files outside the folder it was cleaning — for example in Documents. Links are now skipped completely.
  • Fixed: the Cleaner reported success even when deletions failed. The Live Log now shows skipped links and items that could not be deleted.
  • Fixed: folder sizes could count data outside the folder
  • Fixed: the first dialog after installation showed the old product name “Redline”
  • Changed: a silent installation no longer starts the app automatically
